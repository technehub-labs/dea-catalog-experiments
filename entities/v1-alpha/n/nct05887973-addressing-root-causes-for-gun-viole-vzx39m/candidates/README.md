# NCT05887973 — Addressing Root Causes for Gun Violence Prevention (ARC-GVP)

> The goal of this study is to help build the evidence base for a locally-relevant youth firearm violence prevention program in Washington D.C., a city experiencing disparities in youth firearm violence outcomes. The main question it aims to answer is: How is youth participation in the summer youth employment program, the True Reasons I Grabbed the Gun Evolved from Risk (The T.R.I.G.G.E.R Project), which is designed to address root causes of gun violence, associated with individual youth behavioral outcomes, including pro-social involvement, aggression, and firearm-related attitudes and behaviors? (NCT NCT05887973; status RECRUITING).
