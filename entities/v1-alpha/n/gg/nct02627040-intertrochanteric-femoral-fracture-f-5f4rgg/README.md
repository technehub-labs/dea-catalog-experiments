# NCT02627040 — Intertrochanteric Femoral Fracture Fixation Trial

> The main goal of the study is to determine which cephalomedullary nail results in a better functional outcome for the patient with an unstable intertrochanteric hip fracture. Subjects will be randomized to fixation with either a Gamma3 cephalomedullary nail or an InterTan cephalomedullary nail. Outcomes will be reviewed over a 12 month follow-up period. (NCT NCT02627040; status UNKNOWN).
