# NCT02320253 — REAL HEALTH-Diabetes: Reach Ahead for Lifestyle and Health-Diabetes

> The goal of this project is to translate the Look AHEAD intensive lifestyle intervention for type 2 diabetes and obesity into usual care at community health centers, comparing an in-person group program (IP), a telephone conference call (TCC) group program, and referral to medical nutrition therapy (MNT), the current standard of care. (NCT NCT02320253; status COMPLETED).
