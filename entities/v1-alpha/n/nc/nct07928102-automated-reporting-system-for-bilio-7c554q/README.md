# NCT07928102 — Automated Reporting System for Biliopancreatic Endoscopic Ultrasound

> This study aims to develop and prospectively validate an automated reporting system to generate structured preliminary biliopancreatic EUS reports using information collected before and during EUS examinations. System development will be completed before prospective validation, and patients included in system development will be separate from those enrolled in prospective validation. The prospective multicenter validation will enroll 420 adults undergoing EUS for suspected or confirmed biliopancreatic disease. Each patient will contribute only the first eligible EUS examination. The primary endpoint is the difference in clinical acceptance rates between system-generated preliminary reports and independently prepared manual preliminary reports. Non-inferiority will be assessed using a predefined margin. A nested endosonographer-reporting substudy will also compare completion time and quality between final reports prepared by endosonographers with and without assistance of a system-generated preliminary report. The study will assess the ability of automated reporting to support accurate and efficient EUS reporting while routine clinical care remains unchanged. (NCT NCT07928102; status NOT_YET_RECRUITING).
