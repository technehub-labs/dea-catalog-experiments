# NCT03628950 — Interscalene Versus Combined Infraclavicular-suprascapular Nerve Blocks

> The aim of this trial is to compare the analgesic efficiency and hemi-diaphragmatic paralysis of the standard ultrasound-guided interscalene (ISB) brachial plexus block with the combined use of costoclavicular approach of infraclavicular brachial plexus block and suprascapular nerve block (ICB-SSB) for patients undergoing arthroscopic rotator cuff repair. Authors hypothesize that the combined use of ICB-SSB could lead to equivalent postoperative analgesic effect to the standard ISB with less hemi-diaphragmatic paralysis. (NCT NCT03628950; status COMPLETED).
