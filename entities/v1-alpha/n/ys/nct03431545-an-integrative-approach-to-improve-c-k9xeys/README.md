# NCT03431545 — An Integrative Approach to Improve Child Outcomes Through Research-based Parent and Teacher Interventions

> The purpose of this study is to learn whether a combination of two research-proven programs, a responsive caregiving parenting program and a teacher training program, will have an effect on infants' and toddlers' language, cognitive, social-emotional, and self-regulation skills. The interventions are designed to specifically target parent use of a responsive, stimulating caregiving style in the home in combination with teacher instructional practices and the use of a responsive interactive style in the classroom. (NCT NCT03431545; status COMPLETED).
