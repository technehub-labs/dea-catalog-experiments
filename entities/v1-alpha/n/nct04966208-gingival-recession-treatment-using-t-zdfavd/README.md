# NCT04966208 — Gingival Recession Treatment Using Two Different Surgical Techniques

> Coronally the advanced flap is considered a predictable treatment of gingival recession but in certain situations, it needs a filler like subperiosteal connective tissue graft (CTG) which is considered as the gold standard treatment approach. This randomized controlled trial compares the clinical benefits and effectiveness of a xenogenic collagen matrix (mucoderm, botiss, dental, Berlin, Germany) as a filler to the subperiosteal connective tissue graft (CTG). (NCT NCT04966208; status COMPLETED).
