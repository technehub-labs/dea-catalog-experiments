# NCT05448469 — Ultrasound-guided Erector Spinae Plane Block Versus Paravertebral Block for Perioperative Analgesia in Patients Undergoing Open Splenectomy

> There are very few randomized controlled trials in open splenectomy surgery, which compare paravertebral block with ESP block. The purpose of this randomized controlled trial is to compare the efficacy of ultrasound-guided paravertebral block with ESP block for perioperative analgesia in open splenectomy . (NCT NCT05448469; status COMPLETED).
