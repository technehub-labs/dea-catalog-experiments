# NCT06073210 — Mental Practice and Therapeutic Exercise in Young Nulliparous Women

> Mental practice (both in isolation and also in combination with real practice) has been shown to improve somatosensory and motor variables but so far no study has taken it into the study of women's health. Through this study we want to offer some interesting data regarding the effectiveness of mental practice combined with physical practice. (NCT NCT06073210; status COMPLETED).
