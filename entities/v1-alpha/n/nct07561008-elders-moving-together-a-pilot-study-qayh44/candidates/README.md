# NCT07561008 — Elders Moving Together: A Pilot Study

> This pilot study evaluates the feasibility and acceptability of implementing the Saskatchewan Forever in Motion (FIM) group exercise program in a First Nations community in northwestern Saskatchewan. The study examines changes in physical activity, social connectedness, and quality of life among older adults participating in a 12-week community-led exercise program. The project also explores access-related factors that support participation in community-based exercise programs. (NCT NCT07561008; status COMPLETED).
