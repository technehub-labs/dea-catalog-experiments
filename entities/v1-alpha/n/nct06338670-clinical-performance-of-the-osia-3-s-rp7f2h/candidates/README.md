# NCT06338670 — Clinical Performance of the Osia 3 Sound Processor Compared With the Osia 2 Sound Processor in Adult Osia Implant Users

> This study aims to investigate the clinical performance of the Osia 3 Sound Processor in comparison to the Osia 2 Sound Processor in adults with mixed or conductive hearing loss or single-sided deafness implanted with an Osia implant. Participants will attend four study visits, where they will complete various hearing assessments using the Osia sound processors. (NCT NCT06338670; status COMPLETED).
