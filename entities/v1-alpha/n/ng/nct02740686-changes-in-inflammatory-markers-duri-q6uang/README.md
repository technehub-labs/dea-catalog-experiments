# NCT02740686 — Changes in Inflammatory Markers During Pulmonary Rehabilitation Based on Exacerbation States in COPD

> This study will examine the inflammatory response to exercise encompassed as part of a standard pulmonary rehabilitation programme in patients with chronic obstructive pulmonary disease (COPD). Patients will be split into two groups, frequent exacerbators or infrequent exacerbators, dependent upon exacerbation history to compare responses to pulmonary rehabilitation amongst phenotypes. (NCT NCT02740686; status COMPLETED).
