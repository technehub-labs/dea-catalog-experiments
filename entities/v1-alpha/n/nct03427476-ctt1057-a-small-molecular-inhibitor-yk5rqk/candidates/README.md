# NCT03427476 — CTT1057, a Small Molecular Inhibitor of PSMA, as a Novel Imaging Agent of Neovascularization in Renal Cell Carcinoma

> The purpose of this study is to test a novel diagnostic PET imaging agent for safety and biodistribution. The agent binds PSMA and is designed to detect Prostate Specific Membrane Antigen expressing tumors, such as has been described for some renal cell carcinoma tumors. (NCT NCT03427476; status COMPLETED).
