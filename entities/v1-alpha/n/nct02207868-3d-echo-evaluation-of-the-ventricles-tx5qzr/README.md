# NCT02207868 — 3D Echo Evaluation of the Ventricles in Sclero Associated Severe PAH

> The aim of the study is to document the left and right ventricular function in patients with sclerodermia associated pulmonal arterial hypertension via 3D echocardiography. The results of this study should help to generate hypothesis for further future studies. The primary hypothesis is that the increased use of modern image guided methods could provide essential aspects for the follow up. (NCT NCT02207868; status UNKNOWN).
