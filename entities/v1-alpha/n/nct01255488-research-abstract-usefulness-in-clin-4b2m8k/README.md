# NCT01255488 — Research Abstract Usefulness in Clinical Decision-making

> To better understand the extent to which family nurse practitioners (FNPs) might use research abstracts in shaping their clinical decision-making under simulated conditions. A secondary point is to examine if and how FNPs might use full-text manuscripts (associated with the abstracts) if made available to them. (NCT NCT01255488; status UNKNOWN).
