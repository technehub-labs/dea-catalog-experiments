# NCT01139294 — Descriptive Study of Cardiac Output During Rehydration With Recombinant Human Hyaluronidase in Pediatrics

> The purpose of this study is to non-invasively study the reflective changes in cardiac output as response to fluid therapy in the pediatric moderate hypovolemia/dehydrated pediatric patients using sub-q rehydration using Hylenex augmented subcutaneous infusion of fluids and electrolytes compared to intravenous methods. (NCT NCT01139294; status COMPLETED).
