# NCT03894813 — Probiotics as Adjuvant Treatment for Bacterial Vaginosis

> The investigators are trying to determine if oral probiotics (Umeta-Miyue, Lactobacillus rhamnosus GR-1 and Lactobacillus reuteri RC-14) (30 days)with metronidazole vaginal suppositories(7 days) is better than using metronidazole vaginal suppositories only in preventing the recurrence of bacterial vaginosis (BV).
