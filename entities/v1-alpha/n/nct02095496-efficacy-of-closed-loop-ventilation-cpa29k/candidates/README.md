# NCT02095496 — Efficacy of Closed-loop Ventilation to Reduced Sleep Disorders

> Sleep's deficiencies are very common in intensive care. Mechanical ventilation is a known factor in this deterioration.The investigators hypothesize that close-loop ventilation mode (Intellivent-ASV) is able to minimize sleep deterioration, adjusting ventilation to the patient needs.
